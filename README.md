# Sarah Drake Allred Portfolio

A responsive, single-page portfolio website starter for Sarah Drake Allred’s instructional design portfolio.

The project now includes the narrative and all 35 artifact images from `Portfolio Narrative and Visuals.docx`. Each project links to a dedicated full-size case-study page with the project introduction, problem, solution, role, skills, an image-led process carousel, and the full uploaded narrative.

## Preview locally

Because this is a static site, it does not require a build step. Open `index.html` in a browser, or run a local server from this folder:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Accessibility notes

The visual system uses the Berry Garden palette with dark plum and berry tones for readable text and links. The site also includes skip links, visible keyboard focus, descriptive image alternatives, announced carousel updates, semantic headings and landmarks, 44px carousel controls, no autoplay, and reduced-motion support. Before calling the site fully conformant, run an automated checker and complete a keyboard and screen-reader review after publishing.
